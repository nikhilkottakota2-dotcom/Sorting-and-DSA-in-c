## 📊 Sorting Algorithms

| Algorithm      |  Best Case | Average Case | Worst Case |
| -------------- | ---------: | -----------: | ---------: |
| Bubble Sort    |       O(n) |        O(n²) |      O(n²) |
| Selection Sort |      O(n²) |        O(n²) |      O(n²) |
| Insertion Sort |       O(n) |        O(n²) |      O(n²) |
| Merge Sort     | O(n log n) |   O(n log n) |      O(n²) |
| Quick Sort     | O(n log n) |   O(n log n) |      O(n²) |

> Complexity can vary depending on the implementation and input conditions.

## 🧠 Learning Approach

For each algorithm, I aim to understand:

1. **Concept** – What the algorithm does
2. **Logic** – How it works step by step
3. **Implementation** – Writing it in C
4. **Example** – Testing with sample input
5. **Complexity** – Time and space complexity
6. **Optimization** – Understanding possible improvements

## 🛠️ How to Run

Clone the repository:

```bash
git clone <your-repository-url>
```

Navigate to the repository:

```bash
cd DSA-Through-C
```

Compile a C program:

```bash
gcc filename.c -o program
```

Run it:

```bash
./program
```

On Windows:

```bash
program.exe
```
